🏆 Proud to share: our project "Golden AI Visionary" won the Excellent Award at the 2025 Best AI Awards!

Our team from National Taiwan Ocean University was recognized in the AI Application; Sdent Category for our project:

"AI Assistant for Automatic Interpretation of Reproductive Medical Images using Vision-Language Model"

The system combines deep learning with a multimodal Vision-Language Model to help embryologists interpret Time-Lapse Imaging (TLI) of embryos — generating semantic descriptions, automated fragmentation and symmetry grading, abnormal cleavage alerts, and full embryo summary reports. The goal: reduce subjective judgment in embryo assessment, improve interpretability of "black box" TLI systems, and support Shared Decision Making (SDM) between embryologists and patients.

🔬 Key features:

Label re-annotation interface for correcting training data
Static and frame-by-frame TLI image interpretation (Dev / Frag / Sym / Blip)
Automated abnormal cleavage detection
Auto-generated embryo summary reports
